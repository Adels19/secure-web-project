About Assessment System

A simple demonstration of secure web communication and client authentication.

PKI & Certificates

The system uses a local Root CA to issue and verify server and client certificates.

mTLS

Mutual TLS allows both the server and the client to authenticate each other using certificates.

HTTPS

All communication with Assessment System is protected using HTTPS and TLS encryption.

OpenSSL

OpenSSL is used to generate private keys, CSRs and certificates for the system.

Client-Side Security

This demo shows why textContent is safer than innerHTML when displaying user input.

Output:

HTML/JavaScript entered here is displayed as plain text and is not executed. This helps prevent XSS (Cross-Site Scripting). Server-side validation is still required.
