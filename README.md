# Assessment System

A simple Node.js web application for online assessments.

## Features

- HTTPS
- X.509 certificates
- mTLS authentication
- Student and Teacher roles
- Online assessments
- Teacher question management

## Technologies

- Node.js
- OpenSSL
- HTML
- CSS
- JavaScript

## Run

```bash
node server/server.js
```

Open:

```text
https://localhost:8443
```

A client certificate is required to log in.
